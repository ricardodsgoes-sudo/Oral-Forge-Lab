# Oral Forge Lab

Site estático do OralForge Lab, laboratório de prótese dental.

## Publicação

Esta pasta contém apenas os arquivos necessários para subir o site em um servidor estático:

- páginas HTML
- `styles.css`
- `pages.css`
- `script.js`
- imagens usadas pelo site em `img/`

Para publicar, envie o conteúdo desta pasta para a raiz do servidor.
